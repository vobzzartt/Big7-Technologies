# Big7 Technologies

### Engineering the Future from Africa

Big7 Technologies is a systems research and engineering lab focused on building the foundational layers of sovereign digital infrastructure. We specialize in distributed systems, high-performance computing, AI infrastructure, and blockchain protocols.

Founded in 2024 by Victor Bodude, the lab was established to break Africa's dependency on foreign infrastructure and build resilient, base-layer systems for the next decade of growth.

## 🛠 Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Email Engine**: Resend
- **Deployment**: Vercel / Independent Bare Metal

## 🚀 Getting Started

### Prerequisites

- Node.js 20+
- npm / pnpm / yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/big7technologies/hq.git
   cd hq
   ```

2. **Install dependencies:**
   ```bash
   npm install
   # or
   pnpm install
   ```

3. **Configure Environment Variables:**
   Create a `.env.local` file in the root directory and add your Resend API key:
   ```bash
   RESEND_API_KEY=re_your_api_key
   ```

4. **Run the development server:**
   ```bash
   npm run dev
   ```

5. **Build for production:**
   ```bash
   npm run build
   ```
